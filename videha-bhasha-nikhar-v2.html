निर्यात

नियम-कोश

स्रोत कोशक सभ प्रविष्टि Review अछि (auto_replace=false)। मूल v2 क ३६० प्रविष्टि सेहो समीक्षा-आधारित राखल गेल अछि। ई शब्द बदलयक प्रमाण नहि, सम्पादकीय परामर्श अछि। Safe केवल निज स्पष्ट नियम लेल उपलब्ध अछि। पहिनुक Safe नियम प्रायः निर्विवाद अछि आ "Safe सभ स्वीकारू" सँ एक्केबेर लागि सकैत अछि; Review नियम प्रसंग-सापेक्ष अछि — प्रत्येक स्थान देखि निर्णय लिअ। अंश-प्रकार नियम वाक्यांश ("होता है" → "होइत अछि") पर चलैत अछि। सभ परिवर्तन एहि ब्राउज़र मे सुरक्षित रहैत अछि।

मूल ३६० नियम अक्षुण्ण। नव कोशसँ ३५२ सीधा-जाँच योग्य प्रविष्टि जोड़ल गेल (एकटा आन्तरिक दोहराव); कुल ७१२ अभिलेख। मूल आ नव कोशक दोहराओल संकेतमे नव कोश सक्रिय, मूल रूप सन्दर्भ लेल सुरक्षित। सभ भाषिक प्रतिस्थापन Review अछि। निर्देशिकाक ५९३ अभिलेख आ सम्पादकीय कोशक ४९४ पूर्ण प्रविष्टि अलग स्रोत-टैबमे सुरक्षित अछि। नोट: एहि कम्प्यूटर पर पहिनेसँ सहेजल निजी नियम सेहो जोड़ल जा सकैत अछि।

विदेह शुद्ध मैथिली निर्देशिका · मूल स्रोत-पञ्जी

स्रोत: ११ अक्टूबर २०२६, चौथ संशोधन। नियम-संग्रहक ५९३ अभिलेख (मूल ५९२ क्रमाङ्क सहित अतिरिक्त उपनियम), सम्पादकीय कोशक ४९४ प्रविष्टि। मूल Word निर्देशिका आ तीनू JSON एहि HTML मे समाहित अछि। बाहरी नेटवर्कक आवश्यकता नहि। सम्पादकीय कोशक auto_replace=false नीति अपरिवर्तित।

प्रतिगमन-परीक्षण · सम्पादकीय जाँच

१७७ सम्पादकीय परीक्षण JSON सँ आयातित। स्वीकृत शब्दरूपक संरक्षण, सन्दर्भ-आधारित सुझावक पहचान आ सीमित यान्त्रिक पाठ-परिवर्तन अलग-अलग मापल जाइत अछि। पूर्ण वाक्य-अनुवाद नहि भेटबकेँ गलत ढंगसँ “उत्तीर्ण” नहि कहल जाएत।

परीक्षण एखन नहि चलल अछि।

ऑडिट

पहिने कोनो .docx खोलू।

नोट: DOCX मे स्रोत-उद्धरण, शैलीगत विकल्प, पाठ-क्रम, Word फ़ील्ड आ जटिल XML संरचनाक अन्तिम मानवीय जाँच अनिवार्य अछि। ई टूल भाषाक अर्थ-सापेक्ष त्रुटि स्वतः सत्यापित नहि करैत।
नोट: Word कखनो-कखनो एक्के शब्दकेँ अनेक formatting runs मे बाँटि दैत अछि। ई टूल अनुच्छेद-स्तर पर जाँच करैत अछि, तेँ split-run शब्द (जेना "किस"+"ी") सेहो पकड़ल जाइत अछि आ प्रतिस्थापन काल स्वरूपण यथासम्भव सुरक्षित रहैत अछि।

सहायता

ई उपकरण विवेकशील सम्पादकीय सहायक अछि, पूर्ण स्वचालित अनुवादक नहि। ४९४ सम्पादकीय प्रविष्टि आ ५९३ नियम-अभिलेख समाहित; सभ स्रोत-प्रतिस्थापन human review पर निर्भर। “आएल/आयल”, “नहि/नै”, “कएल/कयल”, “होयत/होएत/हएत” मान्य लेखक-विकल्प अछि। मूल उद्धरण डिफॉल्ट रूपेँ सुरक्षित अछि।

कार्य-क्रम

१. पाठ-समीक्षा मे .docx अपलोड करू — मुख्य पाठक संग header, footer, footnote, endnote सेहो जाँचल जाएत।
२. रंग-संकेत: Safe निर्विवाद सुझाव, Review प्रसंग-सापेक्ष, शब्द-संग्रह वर्तनी-सुझाव, Spacing विराम-सफाई, सतर्कता लिंग-क्रिया संकेत।
३. प्रत्येक सुझाव पर: ✓ स्वीकारू · ✗ छोड़ू · ✎ प्रतिस्थापन बदलू · ★ स्थायी नियम बनाउ।
४. "Safe सभ स्वीकारू" सँ निर्विवाद सुझाव एक्केबेर स्वीकृत करू, फेर Review सभ देखू।
५. ⬇ संशोधित DOCX — मूल स्वरूपण यथासम्भव सुरक्षित रहत।

स्थायी सुधार-शब्दकोश

जँ कोनो शब्द बेर-बेर गलत भेटैत हो (यथा: किसी → कोनो), त झट-नियम, ★ बटन, अथवा नियम-कोश क Bulk सुविधा सँ स्थायी नियम बनाउ। नियम JSON रूप मे निर्यात/आयात कऽ दोसर कम्प्यूटर पर लऽ जा सकैत छी। पुरान संस्करण (v1) आ एहि टूलक पूर्व-रूपक JSON सेहो आयात होइत अछि।

सन्दर्भ शब्द-संग्रह (वर्तनी-जाँच)

शुद्ध मैथिली शब्दक सूची (.txt — प्रति पंक्ति एक शब्द, अथवा .json) आयात करू। तखन दस्तावेजक जे शब्द सूची मे नहि अछि आ सूचीक कोनो एक शब्द सँ मात्र एक अक्षर/मात्रा भिन्न अछि, तकर वर्तनी-सुझाव देखाओल जाएत। सूची IndexedDB मे स्थायी रूपेँ सुरक्षित रहैत अछि। मैथिली thesaurus वा कल्याणी-कोश सँ निकालल शब्द-सूची एतय उपयोगी हएत।
